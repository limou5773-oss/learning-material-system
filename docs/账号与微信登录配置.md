# 账号功能与微信登录配置

2026-10-28。个人昵称/密码修改、微信登录/绑定/解绑、卡片删除已补齐实现；真实微信效果需要有效小程序AppID联调。本轮没有操作用户数据库或真实微信账号。

## 已有数据库先升级

后端现在会查询真实微信绑定状态，因此已有开发库必须先新增 `wechat_binding` 表。先在数据库客户端选中原 `application.yml` 指向的数据库，执行一次：

`database/updates/20261028_wechat_binding.sql`

本文件只新增绑定表，不重建或清空已有账号和学习资料。不要为升级重新导入整个初始化SQL。首次建空库才使用 `backend/src/main/resources/db/migration/learning_material_system.sql`，该完整文件也已包含新表。按用户当前单文件手动管理方式，Flyway保持关闭。

## 微信配置

仍直接修改原文件 `backend/src/main/resources/application.yml`：

```yaml
lms:
  wechat:
    enabled: true
    app-id: "填写你的小程序AppID"
    app-secret: "填写对应AppSecret"
```

这是已有 `lms.wechat` 节点的填写示例，不要额外添加第二个 `lms`。前端 `miniprogram/project.config.json` 的 `appid` 也须改为同一小程序的真实AppID。当前游客号 `touristappid` 不能作为真实微信身份验收环境。AppSecret只放后端；不发到聊天、不放小程序、不上传GitHub。修改后重启后端、重新编译小程序。

未配置时微信按钮会明确提示暂未开放，账号密码登录仍可使用；没有模拟openid或默认微信账号。

## 使用流程

- Web和小程序“我的信息”可修改昵称。昵称更新后页面同步显示，不要求重新登录。
- 修改密码输入原密码和新密码；成功撤销Web与小程序的全部现有会话，重新登录。密码不自动去首尾空白，不接受全空白密码。
- 首次用已有账号密码登录小程序，在“我的”点击绑定微信；客户端调用wx.login取得临时code，服务端向微信换取身份并保存绑定。
- 后续在小程序登录页点击微信登录。未绑定时提示先登录已有账号再绑定，不自动创建或合并账号。
- 解绑需填写当前密码；成功后所有小程序会话失效，Web会话保留，资料不删除。Web也可查看绑定状态并验证密码解绑。
- Web及小程序卡片详情提供删除入口，确认框说明子卡片晋根和关系/收藏/布局引用清理影响；版本冲突时必须重新读取，不能直接覆盖。

## 接口与错误

新增/补齐 `PATCH /users/me`、`POST /auth/wechat-sessions`、`POST/DELETE /users/me/wechat-binding`、`DELETE /cards/{id}?version=N`，统一前缀 `/api/v1`。见 `docs/接口契约.yaml`。

旧密码错误422 CURRENT_PASSWORD_INCORRECT；未绑定409 WECHAT_BIND_REQUIRED；身份占用409 WECHAT_BIND_CONFLICT；账号已绑定别的微信409 USER_WECHAT_ALREADY_BOUND；微信配置缺失503 WECHAT_NOT_CONFIGURED；code无效422 WECHAT_CODE_INVALID。卡片删除404隐藏他人/已删对象，409携带当前版本。

## 实现约束与验证范围

保留Controller → Service接口 → ServiceImpl → Mapper。敏感写入在用户行锁内重新校验会话；微信网络交换不持数据库锁。绑定唯一键限制一用户一身份以及(appid,openid)唯一；openid只来自服务端微信响应，session_key不保存或下发。只在请求/微信响应边界做必要校验，不跨层重复兜底；数据库与权限错误不伪装为成功。

本轮仅做新功能定向检查、必要编译和Web构建，不运行完整回归，不代表真实微信/真实OCR/真实模型验收通过。微信请求协议参照 [微信官方接口](https://developers.weixin.qq.com/miniprogram/dev/server/API/user-login/api_code2session.html)；官方页面本轮无法抓取，调用方式另核对了 [WxJava作者实现](https://github.com/binarywang/WxJava/blob/develop/weixin-java-miniapp/src/main/java/cn/binarywang/wx/miniapp/api/impl/BaseWxMaServiceImpl.java)。
