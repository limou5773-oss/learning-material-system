# Web前端设计方向

日期：2026-10-31。阶段：已按用户确认的方向实施，并完成本轮定向浏览器验收。

## 目标与约束

面向每天管理学习资料的学生，以及处理用户、审核和任务的平台管理员。普通用户先看到资料和下一步操作，管理员先看到统计与待处理事项。视觉方向为安静、清晰、蓝白圆润的学习工作台；通过标题、留白、细边框与小图标形成层级。

沿用现有Vue3、Element Plus、ECharts、UiIcon、WorkspaceLayout及CSS变量；保留业务内容、路由和交互。管理员和普通用户继续分开，管理员导航统计大屏在首位。设置操作使用弹窗。不增加设计装饰依赖或外部字体请求，不上传项目截图到外部服务。

依据：现有style.css中的配色、4px间距刻度与圆角变量；WorkspaceLayout的左侧导航和移动抽屉；此前用户提供的工作台参考图仅作为布局依据。识别细节为左栏浅蓝选中态与页面主操作的一致蓝色，正文区域保持安静。

## 配色

| 用途 | 沿用值 | 规则 |
|---|---|---|
| 主操作 | #2C71E4 | 主要按钮、选中和焦点 |
| 主操作悬停 | #2265CF | 悬停与按下反馈 |
| 浅蓝底 | #EEF4FF | 导航选中、轻量辅助按钮 |
| 页面背景 | #F4F7FB | 整体工作区 |
| 面板 | #FFFFFF | 列表、编辑器、统计区 |
| 次级表面 | #F6F9FD | 输入背景、轻量分区 |
| 正文 | #17253C | 标题、主要信息 |
| 次级文字 | #66788F | 元数据、帮助信息 |
| 分隔线 | #E7ECF3 | 同级面板边框与分隔 |

成功、警告、危险继续沿用现有语义色，始终附带状态文字；不改变图表的数据含义，不添加大面积渐变或装饰性颜色。

## 字体

中文使用PingFang SC、Microsoft YaHei及系统无衬线回退；英数字沿用本机可用Inter及系统回退，不额外下载。正文14px、行高1.6；表单和列表14px；辅助信息12px；小标题16px/600；区块标题18px/600；页面标题26px/600，窄屏22px。统计主数字28–32px，采用等宽数字。普通正文不使用浅灰小字承载关键信息。

## 布局

目标视口：1440x900、1024x768、390x844。宽屏左栏240px、顶栏64px，主内容使用可用宽度；内容边距24–32px。侧栏两侧内边距16px，导航行最小48px、图标18px、图文间距12px；组间24px、组内8px。

宽屏工作区采用12列：资料和卡片列表占主要区域，必要的辅助区占3–4列；统计大屏先总览指标，再趋势和分布，再明细与口径，禁止卡片层层嵌套。个人中心采用账号摘要、设置列表、弹窗编辑，避免多个展开表单挤占首屏。管理员账号不展示学习入口或微信绑定。

中屏主区优先，辅助栏移至下方；窄屏左栏改抽屉，内容单列，边距16px，工具栏换行，主按钮可占整行。表格在自己的容器横向滚动，不让整页横向溢出。长标题换行，完整内容可在详情查看。

## 组件与间距

统一使用4、8、12、16、24、32px间距。当前圆角变量沿用8、10、14、18px：标签8px，输入框和按钮10px，同级面板14px，弹窗18px。面板内边距24px、窄屏16px，同级面板间距24px。

按钮和输入高度40px，触屏操作至少44px。一个操作区保留一个主按钮，次要操作使用描边或文字按钮；删除等危险动作有明确确认。表格行高至少52px、元数据弱化、操作位置一致。图标尺寸和基线一致，纯图标按钮提供可访问名称。

弹窗宽度按内容采用480、640、800px，最大不超过视口减32px；标题、内容、页脚分区，内容过长时内部滚动，按钮保留在页脚。关闭返回触发按钮焦点，Esc行为与未保存提示一致；提交中禁止重复提交，保留现有路由保护。

焦点轮廓清晰，不能仅靠颜色表示选中或错误。动效约150–180ms，仅用于状态切换；尊重系统减少动态效果设置。

## 内容状态契约

| 状态 | 触发 | 可见反馈与下一步 |
|---|---|---|
| 加载 | 请求未完成 | 稳定骨架或进度，禁用重复提交；只在支持取消的流程提供取消 |
| 空数据 | 成功返回空集合 | 区分首次使用和筛选无结果，提供新建或清除筛选 |
| 错误 | 网络或接口失败 | 保留输入，说明错误并允许重试，不冒充空列表 |
| 部分可用 | 部分上传或来源不可用 | 保留成功部分，标注失败项和原因，允许针对性重试 |
| 成功 | 写入完成 | 明确成功并显示已保存内容；只有接口支持时提供撤销 |
| 权限 | 未登录、权限不足、审核受限 | 说明边界，提供登录、返回或重新送审入口 |

## 实施次序与验收

先统一公共变量和布局，再处理资料与卡片列表、编辑与上传、个人中心，最后统一管理端表格和弹窗。每批只改对应页面，不扩大到业务逻辑。

本轮已检查1440x900、1024x768、390x844三个视口，覆盖长内容、移动导航焦点、键盘、主要触控目标和减少动态效果，以及六类内容状态。截图与JSON保存在本机acceptance-output/workspace-design，证据检查器通过。部分来源受限使用浏览器响应夹具，其余真实与受控状态的边界见《Web设计规范实施记录》。本轮结果不等于全站无障碍认证或后端全量验收。


## 全站顶部与页头规范补充（2026-10-31）

用户要求所有类似页面删除顶部面包屑，并先明确页面布局及组件规范再实施。

范围：共用WorkspaceLayout的学习端与管理员端，包括资料、卡片、整理任务、通知、账号、管理列表和统计页面。删除顶部“学习空间 / 当前页面”及“平台管理 / 当前页面”，保留移动导航按钮、账号、通知和新建菜单；左侧导航保留当前选中状态，各内容区保留自身标题。

页头采用安静紧凑的工具型排版：标题26px/600、窄屏22px；说明14px、行高1.6，与标题间隔8px，允许自然换行。桌面与中屏使用左右两列，标题说明占可收缩主列，操作按钮占内容宽度；不再因为说明文字自然宽度而把整组操作挤到下一行。窄于820px改为上下两行，操作组根据实际按钮数量等宽排列。

新建笔记保留主按钮，上传图片和PDF保留描边按钮、原图标和原路由；控件高度40px、窄屏44px，圆角10px、组内间距12px，图标16px。页头不另加面板、底部分隔线或说明装饰，距筛选或下一内容区24px。沿用已有蓝白配色与系统字体，不扩展业务功能。

定向验收视口1440x900、1024x768、390x844，另检查768px下的换行；确认学习端和管理员端均无顶部面包屑、按钮文字完整、移动菜单仍可用、链接路由保持原样。该公共页头不读取异步数据，加载/空/错误/部分可用数据状态继续由各业务内容区负责，不为静态页头新增状态或回归全业务。
