# 登录页视觉方向 · Editorial（杂志编辑）

日期：2026-10-31　范围：仅 `web/src/views/LoginView.vue` 的 template 与 style
验证：304/304 前端测试通过、`vue-tsc` 0 错误、`vite build` 成功
方法：`frontend-design` 技能（Direction Lock → Foundations → Composition → Atmosphere → Motion → 反 AI 味自检）

---

## 一、定调说明（Design Direction Note）

**目的**　让第一次打开平台的大学生觉得这是一个「用来认真读书的地方」，而不是又一个后台系统。

**调性**　Editorial / magazine，克制版。不用渐变、不用玻璃拟态、不用大圆角卡片；靠排印层级、规则线与栅格秩序建立秩序感。

**字体**　展示字 = 中文衬线栈（`Source Han Serif SC → Noto Serif SC → Songti SC → STSong → SimSun`），标题 55px、行高 1.34、字距 +0.012em；正文 = 平台既有的无衬线（Inter + 苹方/雅黑）。这是杂志典型的「一扬一抑」配对：衬线负责气质，无衬线负责可读性。

> 没有引入 Web Font。约束要求不改变资源引入方式，且中文衬线体积过大；系统宋体在 Windows（SimSun）、macOS（Songti SC）都能命中，冷启动零请求。

**配色**　主导表面 = 纸白 `#fff` 与页面冷灰 `#f4f7fb`；强调 = 既有品牌蓝 `--brand #2c71e4`，只出现在第二行标题、色标、按钮、聚焦线上；墨色 = `#1b2a3f`（暖近黑，非纯黑）。60/30/10 的分配：白与灰占 90%，蓝色只做点睛。

**记忆点**　标题下方那条 92px 的细规则线，右接一章式元信息「笔记 · 课件 · 灵感」；配合页眉的 `LEARNING LIBRARY / NO.01 — 2026`，把登录页做成「一期刊物」的封面。访客可能记不住按钮，但会记住这道线。

## 二、设计令牌

组件内新增局部变量（不污染全局 `:root`）：

```css
.login-editorial {
  --serif: "Source Han Serif SC", "Noto Serif SC", "Songti SC", "STSong", "SimSun", Georgia, serif;
  --ed-ink: #1b2a3f;    /* 墨色：标题、卡片标题 */
  --ed-muted: #5a6b82;  /* 正文：导语 */
  --ed-faint: #5f7085;  /* 次要：页眉、章节注、标签、卡脚 */
  --ed-rule: #cfd9e8;   /* 规则线 */
}
```

颜色、圆角、阴影仍取自全局令牌（`--brand`、`--brand-hover`、`--r-md`、`--line`），没有硬编码新的品牌色。

## 三、构成与实现

### 1. 与非对称栅格

- 两栏：`minmax(0, 1.55fr) minmax(320px, 388px)`，间距 84px。左栏是阅读区，右栏是操作区，宽度比约 1.55 : 1。
- 表单卡 `max-width: 388px`，`justify-self: end` 贴右——刻意让它比左栏内容更靠外，形成「正文宽、单据窄」的刊物落差。
- 页眉底线的右端与卡片顶边同为 178px，两条水平结构在同一条基线上。

### 2. 期刊页眉

```
LEARNING LIBRARY                    NO.01 — 2026
────────────────────────────────────────────────
```

10.5px、字距 0.2em、全大写、等宽数字（`font-variant-numeric: tabular-nums`），下方 1px 规则线收口。这是整页第一个「刊物信号」。

### 3. 三栏索引（原三个圆点特性）

原设计的 `• 双端资料同步 • AI 智能整理 • 知识卡片积累` 是典型 AI 味排版：圆点 + 图标 + 居中横排。改为**编号索引**：

```
01                    02                    03
双端资料同步            AI 智能整理            知识卡片积累
```

序号用 10px + 0.18em 字距做定位标记，栏间用 1px 竖线分隔，整体压一条上横线——这是杂志目录页的做法。

### 4. 表单卡：从「软卡片」改「单据」

| 项 | 旧 | 新 |
|---|---|---|
| 圆角 | 18px | 4px |
| 边框 | 1px 淡边框 + 大阴影 | 1px `#d5dfec` 硬边框 + 极浅投影 |
| 顶部 | 无 | 3px 主色色标（出血到边框外 1px，模拟印刷色带） |
| 输入框 | 四面描边 + 灰底 | **底线式**：只留 1px 下边框，透明底，聚焦时变 2px 主色底线 |
| 按钮 | 10px 圆角 | 2px 直角，字距 0.04em，悬停时字距微张到 0.07em |

底线式输入是印刷表格的经典处理，也是这页最容易被认出来的细节之一。Element Plus 的 `.el-input__wrapper` 通过 `:deep()` 重置为 `box-shadow: none; border-radius: 0; border-bottom: 1px solid`，聚焦态用 `box-shadow: 0 1px 0 0 var(--brand)` 叠出 2px 底线，不改变组件行为。

### 5. 动效：一次编排，不是一堆微交互

| 组 | 元素 | 延迟 | 动作 |
|---|---|---|---|
| 1 | 页眉 | 40ms | 上移 14px 淡入 |
| 2 | 空间标签 | 100ms | 同上 |
| 3 | 主标题 | 160ms | 同上 |
| 4 | 表单卡 | 200ms | 同上 |
| 5 | 规则线 | 240ms | `scaleX(0 → 1)` 从左向右生长，720ms |
| 6 | 导语 | 300ms | 上移淡入 |
| 7 | 三栏索引 | 360ms | 上移淡入 |

统一缓动 `cubic-bezier(.16, 1, .3, 1)`，只动 `opacity` 与 `transform`。全部包在 `@media (prefers-reduced-motion: no-preference)` 内，`reduce` 下所有元素直接呈现终态。

### 6. 响应式

- **≤1080px**：切单列，卡片放宽到 460px，间距 84 → 32。
- **≤620px**：标题降到 32px；**三条索引隐藏**。原因是 390px 下索引会把表单卡推到折叠线以下，登录按钮落在首屏之外——移动端优先保证「能登录」。隐藏后按钮回到 771px，进入 844px 首屏。

## 四、反 AI 味自检（12 项逐条）

| # | 检查项 | 结论 | 依据 |
|---|---|---|---|
| 1 | 展示字体是否为默认字体 | **通过** | 标题用中文衬线栈，不在 Inter/Roboto/Arial/system-ui 禁用清单内 |
| 2 | 是否白底紫（蓝）渐变 | **通过** | 纯白 + 冷灰，无任何渐变；蓝色只做单点强调 |
| 3 | 是否「居中标题 + 副标题 + 两按钮 + 三卡」 | **通过** | 非对称两栏 + 期刊页眉 + 编号索引，无三卡矩阵 |
| 4 | 是否一排同样的圆角卡 + 居中图标 | **通过** | 单张单据式卡片：方角、硬边框、顶部色标、无居中图标 |
| 5 | 图标是否纯装饰 | **通过** | 全页只剩 1 个 `spark`（标识「个人学习空间」），原有 3 个装饰图标已移除 |
| 6 | 文案是否有「赋能/新一代/释放潜力」 | **通过** | 文案沿用原句，未新增营销词 |
| 7 | 动效是否统一 300ms 淡入上浮 | **通过** | 7 组错峰 40–360ms，规则线用生长而非淡入，两段不同时长（620/720ms） |
| 8 | 是否纯色平背景、零氛围 | **部分** | 只有规则线与分栏线，**刻意没加纹理/噪点**。理由是「克制」方向下，纸纹会与冷灰底冲突并把页面推向「文艺风」；靠线条与留白建立层次 |
| 9 | 换个 Logo 是否变成别家产品 | **通过** | 页眉期号、索引编号、底线输入三件套构成具体语境，不是通用模板 |
| 10 | 状态是否覆盖 | **通过** | 悬停（底线加深、按钮字距张开）、聚焦（2px 主色底线 + `:focus-visible` 2px 描边）、错误（`el-alert` + 输入框红底线）、加载（`el-button` loading）、禁用（Element 默认） |
| 11 | 是否有可描述的记忆点 | **通过** | 92px 细规则线 + `NO.01 — 2026` 期号 |
| 12 | 可访问性 | **通过** | 见下节 |

**第 8 项如实标为「部分」**，这是设计取舍而非疏漏：技能本身也强调「复杂度匹配方向」，极简/克制方向上加纹理属于过度装饰。

## 五、可访问性与响应式实测

**对比度**（WCAG 相对亮度公式核算）

| 文本 | 前景 / 背景 | 比值 |
|---|---|---|
| 主标题 | `#1b2a3f` / `#f4f7fb` | ≈ 12.5:1 |
| 导语 | `#5a6b82` / `#f4f7fb` | ≈ 5.0:1 |
| 次要文字（页眉、标签、卡脚） | `#5f7085` / `#fff` 与 `#f4f7fb` | 5.1:1 / 4.6:1 |
| 索引正文 | `#43566f` / `#f4f7fb` | ≈ 7.0:1 |

初版曾用 `#8393a8` / `#93a2b6` 做次要文字，实测仅 2.9–3.7:1，未过 4.5 线，已统一改为 `#5f7085`——弱化改由字号（10–11px）与字距（0.16–0.2em）承担，而不是靠降低灰度。

**其他**

- 焦点可见：`:focus-visible` 2px 主色描边 + 2px 偏移（沿用全局规则）。
- 触控目标：按钮 46px（过 WCAG 2.5.5 的 44px 线）；输入框 41px，低于 44 但远高于 2.5.8（AA）的 24px 线，且横向宽度充足。若按 AAA 严格验收，把 `min-height: 41px` 调成 44px 即可。
- 语义：`section` + 唯一 `h1` + `h2`、`aria-labelledby="login-title"` 保留、装饰线 `aria-hidden="true"`。
- 降级：`prefers-reduced-motion: reduce` 下无任何动画。
- 三档体积检查：1512 / 1200 / 390 均无横向滚动、无元素裁切、标题不溢出。

## 六、后续状态（2026-10-31 更新）

初版交付时列出 3 条遗留，现均已在「全站铺开」这一轮修掉：

| 遗留 | 处理 |
|---|---|
| 390px 页头溢出（`创建账号` 被裁） | 在 620 断点收小品牌字号（13px）、图标（30px）、注册按钮内边距，实测 390px 下完整可点 |
| 「登录」链接在登录页冗余 | 用 `.header-links a.router-link-exact-active { display: none }` 隐藏当前页入口，DOM 不变 |
| 按钮 hover 字距动画引起重排 | 改为只动 `background` / `box-shadow` / `transform: translateY(-1px)`，并补 `:active` 回弹 |

此外，本页的样式已从 `scoped` 提升为全局 `.editorial-auth` 层，登录页与注册页共用同一套版式（见 `Editorial全站改造记录.md`）。

## 七、如何回退

改动集中在单文件。`git checkout -- web/src/views/LoginView.vue` 即可完全还原；样式全部写在组件 `scoped` 内并带 `.login-editorial` 前缀，不影响其他页面的 `.auth-layout` 与 `.auth-card` 全局规则。
