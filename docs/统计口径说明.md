# 统计大屏与指标口径

ADMIN登录Web后进入“统计大屏”。普通账号不能访问平台统计接口。页面只读聚合结果，不返回账号明细、笔记正文、文件路径、提示词或密钥；小程序不复制此后台页面。

## 日期范围

页面默认最近7个上海自然日：今日减6天至明日00:00。结束日期不包含在内，例如开始10月20日、结束10月23日代表20、21、22日。最多查询90个自然日，前端显式提交from/to及timezone=Asia/Shanghai；后端校验并转换UTC，不依赖电脑所在时区。

例如上海2026-10-20 00:00至2026-10-23 00:00，对应UTC `2026-10-19T16:00:00Z` 至 `2026-10-22T16:00:00Z`。from包含、to不包含。缺参或非法时间格式400；非上海整日边界、无效时区、反向/空/超长范围422。不会自动纠正用户错误输入后返回另一范围。

## 当前库存和期间事件

| 指标 | 来源及范围 |
| --- | --- |
| 当前有效资料 | 查询时未删除资料，包括已归档；不受日期范围影响 |
| 当前受限资料 | 上述有效资料中RESTRICTED数量，属于有效资料的子集 |
| 当前学科分布 | 上述有效资料按trim学科分组，空学科归未分类；完整返回，按数量降序/名称升序 |
| 新建资料趋势 | 范围内material.created_at事件，包括后来删除者；上海自然日逐日返回，缺日为0 |
| 任务状态 | 范围内创建任务的当前状态，排队/运行/待确认/成功/失败/取消六种状态补0 |
| 任务完成率 | 成功/(成功+失败)，排队、运行、待确认和取消不进分母；分母0返回null，页面显示暂无可计算任务 |
| 曾生成合格候选的任务 | 范围内创建任务存在valid=true的ai_result，包括CANDIDATE、CONFIRMED及后来INVALIDATED；每任务只计一次 |

候选计数包含明确标注的MOCK流程测试。候选结构校验通过和用户确认完成是不同事件；上述数量及完成率不能作为智能体输出质量、学习提升或真实模型效果结论。

各聚合查询在同一短只读REPEATABLE_READ事务中读取同一数据库快照。当前库存与指定期间事件有意分开，不因为查询过去日期而把“当前库存”说成历史库存。

## 调用、重试和费用

实际请求尝试分别来自`model_attempt`和`ocr_attempt`，使用started_at范围、只计dispatched=1，包含SUCCESS/FAILED/RUNNING/UNKNOWN及明确重试。dispatched表示可能发出，并不等于第三方成功处理或账单已确认。一个任务可产生多次请求；任务创建在范围外而请求开始在范围内，仍计请求。

缓存、本地文字提取、校验、关键词检索和`ai_tool_call`外层工具步骤不计作外部请求。工具步骤与实际请求不是一一对应，不能重复相加。

V17为模型记录逻辑step_no及step_attempt_no；同一步第2次起算重试。后续正常规划和首次生成即使全局attempt_no大于1，也不算重试；OCR继续按同任务同页的attempt_no大于1判断。历史模型记录没有可靠步骤归属，保留NULL，返回unknownRetryAttempts单列，不猜测为重试或无重试。

费用仅汇总明确非负cost且币种标记为3位大写字母的尝试，按币种分别返回amount十进制字符串及knownAttempts；不进行汇率折算或跨币种加总。明确提供0允许显示0。缺失金额、负数、缺失/无效币种的已发送尝试计入unknownCostAttempts，不丢记录，也不补成0费用。

当前腾讯云和DeepSeek适配器没有提供可确认的金额/币种，保持未知，不根据token数估价。大屏显示“未提供”及未知次数。软件测试中人为构造的金额只验证分组、精度和空值，不能作为实际厂商账单或论文成本数据。

## 图表与验收

页面使用按需加载的ECharts模块与SVG，尺寸变化resize，卸载dispose；学科等用户输入按文本呈现，不拼接HTML tooltip，并提供表格/文字数据。没有事件时显示空状态，不能用固定增长数字、假扇区或0%掩盖未知。

实现参考：[Apache ECharts模块导入](https://echarts.apache.org/handbook/en/basics/import/)、[容器尺寸与释放](https://echarts.apache.org/handbook/en/concepts/chart-size/)。实际软件验证、已知数据集手算对照及截图见[D23记录](../tasks/evidence/D23.md)。真实AI/OCR与原生微信验收仍按既有待办执行。
