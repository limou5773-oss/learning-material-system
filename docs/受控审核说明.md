# 受控审核使用说明

本轮实现用户主动送审，没有自动敏感内容识别或规则扫描。管理员账号仍通过[显式初始化](管理员初始化与用户管理.md)建立，不能自行注册管理员。

## 本人送审和修正

1. 在Web或小程序打开本人资料详情，阅读授权说明、填写送审原因并确认。授权仅包含页面所示版本的正文和原文件，不包含其他私人资料。
2. 送审同时提交页面资料version；若资料已在另一端修改，返回409，保留原因，刷新并阅读新版后再送审。同版本只能送审一次。
3. 详情审核历史显示每次送审版本、状态和处置原因。审核决定也生成站内通知，可跳回本人资料；微信订阅消息尚未开通。
4. 驳回后资料标记RESTRICTED，仍可本人查阅正文和原文件；不能继续AI整理。编辑笔记保存新版本，再主动送审。文件内容暂不支持原位替换，可修改元数据或上传修正后的新资料；不要声称修改标题已修正原文件中的问题。
5. 批准解除限制；已取消的旧任务不会自动恢复，需本人重新选择处理目标、同意外部处理并新建任务。

## 管理员处理

1. ADMIN登录Web后进入“内容审核”，默认待审核，可按状态和分页查看。普通用户不能访问管理接口。
2. 队列只有送审标题、类型、归属、理由、时间及状态，标题/类型为送审快照。用户编辑或删除后，旧记录仍保留，但禁止查看和处置。
3. 选择当前待审项，填写查看理由；后台写CONTENT_VIEW审计后才返回正文。需要查看图片/PDF时，另行通过受控文件接口读取，每次产生FILE_VIEW。查看记录仅对当前管理员的当前会话有效。
4. 阅读后填写决定理由，选择批准或驳回并确认。review.version防并发，资料version确保决定针对授权内容；冲突409时刷新，不自动重试或覆盖。
5. 切换选择、筛选、页面、账号或权限，以及完成处置时，页面清除已显示正文和临时文件预览。浏览器已经取得的数据无法由服务端远程撤回；后续读取仍会重新检查授权。

## 一致性及边界

审核决定、资料访问状态、未完成任务取消、REVIEW_DECISION审计及REVIEW_DECIDED站内通知在同一短事务提交。驳回取消QUEUED、RUNNING和WAIT_CONFIRM任务，活动工具/OCR/模型尝试标UNKNOWN/SOURCE_RESTRICTED，旧执行租约不能写回结果。已经获准开始的外部调用不能撤回，不能保证第三方未收到；未知用量和费用不能补零。

决定递增审核记录version，不递增资料内容version。本人PATCH产生新内容版本后可以重新送审，限制保留到批准；送审本身不解除限制。审核状态和资料删除状态分开，删除不伪造审核决定。

数据库以Flyway V16迁移为准，不手动导入拟议SQL。审计记录操作者、会话ID、资料/审核ID、原因、前后状态和UTC时间，不保存正文或访问令牌。原文件没有公开永久URL；管理员必须按同会话鉴权路径读取。

软件验证使用自编笔记和测试文件。腾讯云OCR、DeepSeek及原生微信效果仍需本机凭证和真实环境验收，不能据本轮测试回填论文实验结果。
