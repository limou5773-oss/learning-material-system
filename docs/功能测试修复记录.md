## 微信人工验收步骤

用户已明确暂时不能扫码或手机授权，以下项目保持待验收：

1. 使用真实小程序 AppID 打开项目，退出游客模式；本机 YAML 的微信配置与该 AppID 对应，确认后端可达。真机调试需局域网地址或已配置的合法 HTTPS 域名，手机上的 127.0.0.1 不能访问电脑。
2. 用独立普通测试账号密码登录小程序，在“我的”点击绑定微信，完成真实 `wx.login` code 交换；确认用户资料显示已绑定，数据库对应关系唯一。
3. 退出账号，点击微信登录；已绑定账号应直接进入同一用户空间，不再要求账号密码。未绑定微信应按页面提示先完成账号绑定。
4. 在测试账号中修改昵称，核对 Web 重新读取后的昵称；修改密码后，旧 Web 与小程序会话应失效，重新登录可用。
5. 只对测试账号执行解绑，核对绑定状态和后续微信登录行为；不得用现有个人账户反复绑定来代替测试账号。
6. 从中间加号分别进入笔记、图片和卡片的既有页面；执行拍照、相册上传、编辑、搜索、收藏、删除卡片并核对 Web 同步。
7. 在本机真实 AI/OCR 配置可用且同意外部处理后，提交一份图片或 PDF，等待解析、查看摘要与引用、确认候选卡片入库；记录任务 ID、通知及两端截图。
8. 核对站内任务完成通知。微信订阅推送需另备后台可用模板 ID 和字段配置，当前未提供，不能标记验收通过。

每项记录实际时间、AppID 所属测试项目、任务或请求 ID、HTTP 状态及截图；不记录 AppSecret、API Key、JWT 或密码。并发锁定已有定向自动化验证，压力、吞吐及真机弱网测试仍未开展，不得据此编写性能数据。
