# F21 管理员脱敏任务监控

管理员登录Web后进入“任务监控”。该页面用于查看任务状态和执行元数据，不授予读取其他用户私人学习内容或代用户执行任务的权限。普通用户不显示该导航，直接访问返回无权限；匿名访问接口401，普通账号403。

## 查询与操作

- 任务列表默认查询全部状态，每页20条，按创建时间及任务ID倒序。可以按六个任务状态筛选，历史任务在源资料删除或受限后仍可列出。
- 创建日期按上海时区选择：起始日包含、结束日不包含；两个边界均可省略或单独填写。接口接收UTC带Z时间，日期限制依据MySQL DATETIME的1000—9999年，分页有界，不附加统计大屏的90天限制。
- 点击一条任务的“查看步骤”读取该任务的脱敏工具记录；工具记录单独分页，按步骤号、尝试号和记录ID升序。刷新、筛选或切换列表页清除旧的步骤选择，避免误把上一任务的步骤显示在新任务旁。
- 页面手动刷新，不自动轮询。加载失败明确显示错误；列表或步骤错误不能被伪装成“暂无数据”，未登录/权限失效会清理旧数据并跳转。
- 后台仅提供GET查询；任务取消、重试和确认仍由资料所有者通过本人业务流程操作。

## 可查看的字段

`GET /api/v1/admin/ai-tasks`每条记录仅返回12字段：`id,userId,materialId,goalType,status,stage,stepCount,errorCode,createdAt,startedAt,finishedAt,durationMs`。三个ID始终为十进制字符串，避免浏览器BIGINT精度损失。

`GET /api/v1/admin/ai-tasks/{id}/steps`每条记录仅返回9字段：`stepNo,attemptNo,toolName,providerKind,status,errorCode,startedAt,finishedAt,durationMs`。两个接口均使用`{items,page,pageSize,total}`分页，默认20，最大100。计数与数据在只读一致性事务中读取，SQL显式选择元数据列，不依赖客户端隐藏私人字段。

接口不返回用户名、资料标题/文件名、补充说明、提示词、来源片段、引用、候选正文、配置/上下文、工具输出摘要、输入摘要、usage或供应商响应。不提供跳转到其他用户原文的链接。目标、状态、阶段、工具和错误采用内部受控标识，未知历史值显示`UNKNOWN`或`UNRECOGNIZED_ERROR`，不会透传不受控自由字符串；无记录的nullable字段保留null。

## 时间与用时口径

任务`durationMs`只在开始和结束时间均存在、结束不早于开始时计算毫秒差，**包含等待用户人工确认的时间**，不能当作模型推理耗时。排队、运行、待确认等没有完整起止的记录返回null，不补零或持续估算；明确0毫秒有效。异常时间跨度显示未知，不包装为0。

工具用时同样只描述本条工具记录的起止跨度。工具可以命中本地缓存、封装一次或多次模型/OCR尝试；工具记录条数不能当作真实厂商请求次数或计费。需要平台实际发送尝试、步骤重试及未知费用统计时使用[D23统计大屏](统计口径说明.md)。

时间筛选为`createdAt >= from AND createdAt < to`。错误的整型/时间格式400，状态、页码/页大小或时间范围不合法422，不存在或无效的步骤任务ID404。数据库/权限故障明确报错，不用空集合掩盖失败。完整Schema见[接口契约](接口契约.yaml)，实际测试/浏览器证据见[F21记录](../tasks/evidence/F21.md)。

日期类型范围依据[MySQL官方文档](https://dev.mysql.com/doc/refman/8.0/en/datetime.html)，事务属性使用[Spring官方说明](https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/annotations.html)。本轮软件样本和模拟步骤只用于验证监控协议，不能作为真实厂商效果、请求或论文实验数据。
