## 首轮失败项定性

| 项 | 现象 | 原因 | 结论 |
|---|---|---|---|
| `PATCH /users/me` 400 | 传 `nickname` 被拒 | 接口字段是 `displayName`，且开启未知字段拒绝 | 脚本写错 |
| `POST /auth/registrations` 400 | 缺必填项 | 必填 `username/password/displayName` | 脚本写错 |
| `POST /materials/files` 400 | 上传被拒 | `title` 是必填 query 参数 | 脚本写错 |
| `PUT /card-layouts/default` 422 | 「卡片和显示顺序不能重复」 | 追加的两项 orderNo 与已有项重复 | 脚本写错，服务端校验正确 |
| `GET /admin/statistics` 422 | 日期范围不合法 | 必须传上海自然日零点对应的 UTC 时刻，跨度 ≤90 天 | 脚本写错，服务端校验正确 |

补充说明：登录成功返回 201、审核通过后再取原文件返回 409，这两项是既有契约，不是缺陷。
