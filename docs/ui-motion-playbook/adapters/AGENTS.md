# UI 动效与交互规则（精简版）

> 完整版在 `C:/Users/24100/.workbuddy/skills/ui-motion-playbook/`（六份 references + 截图）。
> 本文件是给 rules 类机制用的浓缩版：先按这里的硬规则做，需要参数/原文时再去查完整版。

## 1. 动效三问（不清就不加）

每个候选动画都必须至少答对一条，否则删掉：

1. 是否表达了一次**状态变化**？（开→关、加载中→完成）
2. 是否**缩短了等待的感知**？（骨架屏、进度、占位）
3. 是否提供了**空间定位**？（从哪来、到哪去、列表里哪一项）

## 2. 时长与缓动（硬规则）

- 微交互 **90-140ms**；hover/展开 **150-200ms**；入场 **200-300ms**；弹窗 **200-260ms**
- 超过 **400ms** 的单次动效必须能说出理由
- 入场用 `ease-out`，**离场比入场更快**（约 70%）
- 推荐曲线：`cubic-bezier(.22, 1, .36, 1)`；带回弹只用于位移 `cubic-bezier(.34, 1.4, .64, 1)`
- 只动 `transform` / `opacity` / `filter`；必须动高度时用 `grid-template-rows: 0fr → 1fr`

## 3. 视觉规则（任何 UI 都用，直接抄）

```
配色：中性色为主，用明暗对比突出主要操作。强调色可选，最多一种。禁用渐变、发光和彩色阴影。
间距：仅用 4 8 12 16 24 32 px。组内间距小于组间间距。
圆角：仅用 6 10 16 px。嵌套圆角：外圆角 = 内圆角 + 内边距。
对齐：同一列元素共用左边缘。
内容：统一一套线性图标。不要表情符号、感叹号或装饰性徽章。
```

## 4. 遮罩层按打断程度选（能轻不重）

提示气泡 → 气泡菜单 → 侧边抽屉 → 底部弹层 → 模态弹窗 → 全屏遮罩

- 抽屉：**筛选时列表还在原地**
- 底部弹层：**出现在手指够得到的地方**
- 模态：**只留给"删不掉的确认"**

## 5. 已知反例（不要做）

- 全屏自定义光标 / 跟随特效（遮数据、无降级、纯装饰）
- 首屏自动循环动画（抢注意力）
- 每行都入场 300ms（行多时压到 150-200ms，错峰 50ms）
- 用 `height: auto` 做展开动画
- 入场动画用 `transform` + `fill-mode: both`（会锁死 hover）

## 6. 必过闸门

- 全部动画在 `prefers-reduced-motion: reduce` 下可关闭
- 动效代码对 `document` / `window.matchMedia` / `requestAnimationFrame` 做存在性判断（Node 测试环境无这些 API）
- 动画失败或环境不支持时，元素停在**终态**而不是隐藏态

## 7. 说人话：用数字不用形容词

```
元素 A 在 <触发> 时，用 <时长> + <缓动>，从 <起始态> 走到 <结束态>；
其中属性 B 变化 <具体数值>，同时属性 C 变化 <数值>。
降级：prefers-reduced-motion 下直接到终态。
```

禁止："丝滑""高级""自然"。必须给：毫秒、像素、透明度、缩放比、颜色值。

> 「叫得出名字，AI 才改得对。」
