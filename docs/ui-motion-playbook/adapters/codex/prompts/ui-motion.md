# /ui-motion — UI 动效与交互规则

现在开始处理当前的 UI 动效 / 交互需求。**先读下面的硬规则，再动手**。如果用户还没说清要做什么，先问一句"你要改哪个界面、想要什么效果"，不要自己编。

## 一、动效三问（不清就不加）

每个候选动画必须至少答对一条，否则删掉：

1. 是否表达了一次**状态变化**？（开→关、加载中→完成）
2. 是否**缩短了等待的感知**？（骨架屏、进度、占位）
3. 是否提供了**空间定位**？（从哪来、到哪去、列表里哪一项）

## 二、时长与缓动（硬指标）

- 微交互 **90-140ms**；hover/展开 **150-200ms**；入场 **200-300ms**；弹窗 **200-260ms**
- 超过 **400ms** 的单次动效必须能说出理由
- 入场用 `ease-out`，**离场比入场更快**（约 70%）
- 推荐曲线 `cubic-bezier(.22, 1, .36, 1)`；带回弹只用于位移 `cubic-bezier(.34, 1.4, .64, 1)`
- 只动 `transform` / `opacity` / `filter`；必须动高度时用 `grid-template-rows: 0fr → 1fr`

## 三、视觉规则（UI 通用，直接执行）

```
配色：中性色为主，用明暗对比突出主要操作。强调色可选，最多一种。禁用渐变、发光和彩色阴影。
间距：仅用 4 8 12 16 24 32 px。组内间距小于组间间距。
圆角：仅用 6 10 16 px。嵌套圆角：外圆角 = 内圆角 + 内边距。
对齐：同一列元素共用左边缘。
内容：统一一套线性图标。不要表情符号、感叹号或装饰性徽章。
```

## 四、遮罩层按打断程度选（能轻不重）

提示气泡 → 气泡菜单 → 侧边抽屉 → 底部弹层 → 模态弹窗 → 全屏遮罩

- 抽屉：筛选时列表还在原地
- 底部弹层：出现在手指够得到的地方
- 模态：只留给"删不掉的确认"

## 五、加载的五种形态

| 形态 | 何时用 |
|---|---|
| 骨架屏 | 首屏、已知结构的列表（骨架条高度**必须等于**真实内容高度） |
| 顶部加载条 | 路由切换（2px，最短展示 200ms 防闪烁） |
| 进度条 | 已知总量（上传/下载/导入） |
| 转圈 | 按钮内、局部小区域 |
| 三点 | 行内等待 |

优先级：有结构→骨架屏；有总量→进度条；都没有→顶部条/三点。转圈是兜底。

## 六、已知反例（不要做）

- 全屏自定义光标 / 跟随特效（遮数据、无降级、纯装饰）
- 首屏自动循环动画
- 每行都入场 300ms（行多时压到 150-200ms，错峰 50ms）
- 用 `height: auto` 做展开动画
- 入场动画用 `transform` + `fill-mode: both`（会锁死 `:hover` 的 transform，改用独立 `translate`）

## 七、必过闸门

- 所有动画在 `prefers-reduced-motion: reduce` 下可关闭
- 动效代码对 `document` / `window.matchMedia` / `requestAnimationFrame` 做存在性判断（Node 测试环境没有这些 API）
- 环境不支持或动画失败时，元素停在**终态**而不是隐藏态

## 八、输出要求

用数字，不用形容词：

```
元素 A 在 <触发> 时，用 <时长> + <缓动>，从 <起始态> 走到 <结束态>；
其中属性 B 变化 <具体数值>，同时属性 C 变化 <数值>。
降级：prefers-reduced-motion 下直接到终态。
```

禁止"丝滑""高级""自然"；必须给毫秒、像素、透明度、缩放比、颜色值。改完告诉用户改了哪个文件、哪一行、怎么关掉。

> 「叫得出名字，AI 才改得对。」
