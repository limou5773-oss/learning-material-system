# 去 AI 味四条规则 + 自检清单

## 可直接抄进提示词的「视觉规则」原文

```markdown
## 视觉规则
配色：中性色为主，用明暗对比突出主要操作。强调色可选，最多一种。禁用渐变、发光和彩色阴影。
间距：仅用 4 8 12 16 24 32 px。组内间距小于组间间距。
圆角：仅用 6 10 16 px。嵌套圆角：外圆角 = 内圆角 + 内边距。
对齐：同一列元素共用左边缘。
内容：统一一套线性图标。不要表情符号、感叹号或装饰性徽章。
```

## 四条规则（按顺序执行）

### ① 控制配色

AI 生成界面的通病：紫蓝渐变打底 + 高饱和强调色 + 自定义色满地跑。

- **底色和文字用中性色，靠明暗对比突出主要操作**
- **强调色可选，最多一种**；禁用渐变、发光和彩色阴影
- 主色 1 个，语义色（成功/警告/危险）各 1 个，中性色阶 3-5 档
- 禁止：彩虹渐变按钮、紫色发光边框、随机 saturate

### ② 统一设计变量

同一个职责只允许一个值。落地做法：

- **间距只用 4 / 8 / 12 / 16 / 24 / 32 px**，不写 13px 这种随手值
- **圆角只用 6 / 10 / 16 px**；**嵌套圆角 = 外圆角 + 内边距**（这条最容易忘，卡片里再套卡片时圆角不递增会显得很脏）
- **组内间距小于组间间距**——同组元素用小的那档，分组之间用大的那档
- 全项目搜一遍十六进制色值，按职责归并（描边/浅底/文字灰/强调）
- 动效时长同样收敛成令牌
- 改动前先搜已有令牌，**不要造第二套**（`--dur-*` 和 `--motion-*` 并存是最典型的自伤）

### ③ 左边缘对齐

视觉轴线错位比颜色错误更容易被感知为"不专业"：

- 侧栏：分组标题 / 图标 / 文字 / 子级竖线，四者对齐成一条轴
- 卡片：标题、正文、数字、脚注的左基线一致
- 表格：表头与单元格 `padding` 相同，不要一边 12px 一边 14px
- 数字列用 `font-variant-numeric: tabular-nums`，否则纵向对不齐

### ④ 删掉多余装饰

AI 最爱加的：装饰性分隔线、每个区块都套圆角边框、emoji 当图标、无意义的渐变光环、卡片里再套卡片。

- 图标统一一套线性图标，**不要表情符号、感叹号或装饰性徽章**
- 判断方法：删掉它，信息是否有损？无损就删。

## 自检清单

### 动效层

- [ ] 每个动画都能回答"动效三问"中的至少一条
- [ ] 同一屏并存的动效类型 ≤3 种
- [ ] 没有自动无限循环的装饰动画（骨架屏扫光除外）
- [ ] 所有动画在 `prefers-reduced-motion: reduce` 下可关闭
- [ ] 只动 `transform` / `opacity` / `filter`，或使用了 `grid-template-rows`
- [ ] 入场动画没有占用 `transform` 与 `:hover` 抢属性
- [ ] 时长在 100-300ms 区间（叙事类除外），主次元素有 40-80ms 差
- [ ] 按钮/弹窗关闭比打开更快

### 视觉层

- [ ] 描边色、浅底色、文字灰都来自令牌，没有近似重复值
- [ ] 数字层级正确：摘要 > 明细（不能让卡内明细比顶部 KPI 还大）
- [ ] 同名信息不在同屏出现两次
- [ ] 左边缘能对齐成轴；数字列用了 `tabular-nums`
- [ ] 空状态不是一行字悬在大块空白里（应有占位框或换成汇总数字）

### 工程层

- [ ] 动效参数来自令牌，不是散落的魔法数字
- [ ] 动效代码对 `document` / `window.matchMedia` / `requestAnimationFrame` 做了存在性判断（Node 测试环境）
- [ ] 动画失败或环境不支持时，元素仍处于**终态**而非隐藏态
- [ ] 首屏加载有骨架屏，而不是白屏或一行"加载中"

## 常见"看起来很努力但很廉价"的做法

| 做法 | 问题 |
|---|---|
| 全屏自定义光标 | 遮数据、无降级、纯装饰 |
| 每个卡片都加 3D 倾斜 | 信息密度场景下干扰阅读 |
| 数字用放大镜式弹跳 | 只在游戏化场景成立 |
| 列表整屏滚动视差 | 后台系统里会晕 |
| 渐变发光按钮 | 与"克制"直接冲突 |
| 每行都入场 300ms | 30 行就是 9 秒的错觉延迟（错峰只解决视觉，不解决总时长） |
