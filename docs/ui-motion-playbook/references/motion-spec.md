## 为什么必须量化

"做一个好看的按钮""加个丝滑的过渡"这类描述，AI 和人都会各自理解成不同东西。可执行的需求必须包含四要素：

**触发 → 属性 → 数值 → 时间曲线**

## 参数模板

```
【元素】在【触发条件】时：
  属性 A：<起始值> → <结束值>，持续 <Xms>，缓动 <cubic-bezier>
  属性 B：...
【反向/复位】：<Xms>，缓动 <cubic-bezier>
【降级】：prefers-reduced-motion 下直接到终态，无过渡
```

## 参考案例：提交按钮三连变

这是"一次点击的三个阶段"，是描述动效的典型范例。

| 阶段 | 触发 | 视觉变化 | 参数 |
|---|---|---|---|
| 1 收缩 | 点击瞬间 | 按钮宽度收窄、文字淡出 | 132ms，`width` 用 `scaleX` 近似；文字 `opacity 1→0` |
| 2 加载中 | 请求发出 | 只留一个 16px 转圈，按钮高度不变 | 转圈 `1.0` 周期旋转；按钮 `padding` 锁定避免抖动 |
| 3 结果 | 响应返回 | 成功：绿色勾 + 保持 800ms；失败：红色 + 抖动 2 次后恢复 | 勾 `scale .6→1` 200ms spring；抖动 `translateX ±2px` 60ms×4 |

要点：**三个阶段按钮的外框尺寸必须锁定**，否则页面会跳一下——这是"生硬感"的最大来源。

## 参考案例：卡片悬停

```
卡片在 hover 时：
  transform: translateY(0) → translateY(-2px)，200ms，cubic-bezier(.2,0,0,1)
  box-shadow: shadow-xs → shadow-md，200ms，同上
  border-color: line → line-strong，200ms
鼠标离开：同参数反向，160ms
降级：reduced-motion 下只保留阴影变化，不做位移
```

## 参考案例：数字滚动

```
数值在数据更新时：
  从旧值 → 新值，520ms，easeOutCubic（1-(1-t)^3）
  每帧用 Math.round 取整，避免长小数
  首帧从 0 起（初次加载）/ 从旧值起（刷新）
降级：reduced-motion 或环境无 rAF 时直接落终值
```

## 参考案例：按钮的四种"手感"

只说"做个好看的按钮"，结果是"一个会变色的方块"。差别在于**动作顺序和数值**，四种可复用的结构：

### 1. 点赞爆粒子 Like Burst
```
做一个点赞按钮（Like Burst）：点击后爱心先缩小到 0.8 倍再弹到 1.2 倍，最后回到 1 倍，
同时由灰色变成红色；爱心周围炸开 8 个彩色小圆点，向外飞散并淡出；
右边的点赞数向上滚动 +1。总时长约 600ms，弹跳使用带回弹的曲线。
```

### 2. 提交按钮三连变 Submit Morph
```
做一个提交按钮三段变化（Submit Morph）：点击后文字淡出，按钮宽度收缩成圆形，
圆形中间出现旋转的加载圆环；1.2 秒后按钮变成绿色并画出对勾；
再过 1 秒恢复原状。收缩约 300ms，使用 ease-in-out。
```
**外框尺寸三个阶段都不能变**，否则页面会跳一下。

### 3. 果冻开关 Jelly Toggle
```
做一个果冻开关（Jelly Toggle）：点击后圆点滑向另一端，滑动途中先横向拉长成胶囊形，
到达终点回弹恢复圆形；底色从灰色渐变为绿色。时长约 350ms，使用带回弹的弹簧曲线。
```
只做平移没有手感，那个"拉长再弹回"才是关键。

### 4. 长按确认 Hold to Confirm
```
做一个长按确认按钮（Hold to Confirm）：圆形删除按钮，按住时外圈进度环顺时针走满，
用时 1.5 秒；中途松手进度环倒退回零；走满后按钮左右轻震一下，变成对勾和"已删除"。
适合删除等危险操作。
```

## 三条决定"高级感"的原则

### 1. 反馈跟着手指走，不跟着控件走

水波纹要从**点击位置**扩散，不是从按钮中心扩散；拖拽/滑动的跟手位移要用指针坐标，不是控件坐标。差这一点，操作就从"有反馈"变成"有反应"。

### 2. 形变优于换元件

同一个交互不要用两个元素交叉淡入淡出，用一个元件做形变：

| 交互 | 错误做法 | 正确做法 |
|---|---|---|
| 汉堡 → 叉 | 汉堡淡出、叉淡入 | 三条线分别 rotate + translate 成叉，一个元件走完全程 |
| 卡片翻面 | 内容整体缩放 | 正反两面各自 `backface-visibility: hidden` + `rotateY(180deg)`，背面预先藏好 |
| 卡片抽走 | 直接 remove | 后面的卡片必须露出堆叠层次，抽走的卡要有位移+缩放退出 |

用户要在切换过程中**始终知道自己在哪**。两个元素交叉淡入会让他短暂丢失位置。

### 3. 多条属性同频

滑块这类控件里，轨道填充、滑钮位置、数值变化**必须同一时长同一曲线**，否则会像三个不同步的零件。同理：开关的圆点、轨道色、标签文字。

## 数字滚动要"慢慢停下来"

错误：`linear` 匀速滚到目标值然后硬停——像电梯急刹。
正确：`easeOutCubic` / `easeOutQuart`，尾部速度趋零。快到终点时肉眼能看出"减速靠站"。

## 参考案例：收起 / 展开

```
进场：ease-out（先快后慢），200-300ms
离场：比进场更快更轻，约为进场的 70%，曲线偏线性
理由：出场时用户已经决定离开，不需要再"表演"一次
```

## 弹窗出现：不要从 0 放大

```
错误：scale(0) → scale(1)
正确：scale(0.9 左右) + opacity 0 → scale(1) + opacity 1，220-260ms
理由：从无到有会显得"炸出来"，从 0.9 左右开始更像"浮上来"，也符合物理直觉
```
原话是"从 9×5 大小放大到原样就够了"——ASR 把 `0.9×0.95` 识别成了 `9×5`，取 0.9 这个量级即可。

## 时长速查

**视频口径**（原话）：小动作 0.1-0.2 秒，弹窗抽屉 0.2-0.3 秒；超过 0.3 秒要能说出为什么。

**Carbon 令牌**（官方规范，可按元素尺寸取档）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `duration-fast-01` | 70ms | 按钮、开关的微交互 |
| `duration-fast-02` | 110ms | 淡入淡出 |
| `duration-moderate-01` | 150ms | 小展开、短距离位移 |
| `duration-moderate-02` | 240ms | 展开、系统提示、toast |
| `duration-slow-01` | 400ms | 大展开、重要系统通知 |
| `duration-slow-02` | 700ms | 背景遮罩渐暗 |

Carbon 的评审清单里还有一条硬指标：**微交互的静态时长应落在 90-120ms**，正好与视频的"0.1-0.2 秒"吻合。

**两条通用原则**：
- 时长跟**位移距离/缩放比例**走——变化越大，时长越长（Carbon 的非线性 duration scale 就是这个道理）
- 入场用 `ease-out`，离场要更快更轻（约进场的 70%）

| 场景 | 参考时长 |
|---|---|
| 按压、颜色、图标 | 90-140ms |
| hover、展开、滑块 | 150-200ms |
| 入场、页面切换 | 200-300ms |
| 模态弹窗进出 | 200-260ms |
| 骨架屏扫光 | ≈1.2-1.6s 循环（经验值） |
| 顶部加载条 | ≈0.8-1.2s 循环（经验值） |

**超过 400ms 的单次动效几乎都需要理由**（多为叙事类动画）。

## 缓动速查

| 用途 | 值 | 来源 |
|---|---|---|
| 通用出场（推荐默认） | `cubic-bezier(.22, 1, .36, 1)` | 项目实例实测值 |
| 需要克制、无回弹 | `cubic-bezier(.2, 0, 0, 1)` | 项目实例实测值 |
| 带轻微回弹（只用于位移/缩放） | `cubic-bezier(.34, 1.4, .64, 1)` | 回弹手感参考 |
| 标准（元素全程可见） | `cubic-bezier(.2, 0, .38, .9)` | Carbon productive |
| 入场（元素出现） | `cubic-bezier(0, 0, .38, .9)` | Carbon entrance |
| 离场（元素移除） | `cubic-bezier(.2, 0, 1, .9)` | Carbon exit |
| 强烈表达（重要时刻） | `cubic-bezier(.4, .14, .3, 1)` | Carbon expressive standard |
| 进度、匀速循环 | `linear` | 通用 |

**Carbon 的一个细节值得抄**：元素离场后如果"还停在视野外、随时会被召回"（比如侧边面板），不要用 exit 曲线，改用 standard 曲线让它**减速**停下，暗示它就在旁边等着。

## 常见参数错误

- 用 `height` / `top` / `width` 做动画 → 触发重排，掉帧；改 `transform` / `grid-template-rows`
- 所有元素同一个时长 → 看不出层次；主元素长、次元素短（差 40-80ms）
- 循环动画没有"跑完就停" → 抢注意力
- 弹窗淡入用了 `ease-out` 但关闭用了 `ease-in` → 关闭会显得拖沓；关闭应更快（约 70% 时长）
