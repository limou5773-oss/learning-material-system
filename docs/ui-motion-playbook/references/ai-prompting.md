# 「跟 AI 说」句式库

> 全部来自视频原话或收尾卡原文。可直接复制进提示词。
> 一条好句子的结构：**元素 + 触发 + 属性 + 数值 + 曲线**。缺数值的句子，AI 只会给你换个颜色。

## 为什么句式重要（原话）

- 「只说做个点赞按钮，AI 多半只会给你换个颜色，**要把顺序和数值写清楚**。」
- 「只说加个加载状态，它多半只会转个圈。」
- 「只说做个开关，它就**平平地滑过去**，没有那个手感。」
- 「只说删除前确认一下，你多半会得到一个**弹窗**。」
- 「只说做个好看的按钮，结果就是**一个会变色的方块**。」
- 「**叫得出名字，AI 才改得对。**」

## 一、四条按钮提示词（原文，可直接抄）

### 01 点赞爆粒子 Like Burst
```
做一个点赞按钮（Like Burst）：点击后爱心先缩小到 0.8 倍再弹到 1.2 倍，最后回到 1 倍，
同时由灰色变成红色；爱心周围炸开 8 个彩色小圆点，向外飞散并淡出；
右边的点赞数向上滚动 +1。总时长约 600ms，弹跳使用带回弹的曲线。
```

### 02 提交按钮三连变 Submit Morph
```
做一个提交按钮三段变化（Submit Morph）：点击后文字淡出，按钮宽度收缩成圆形，
圆形中间出现旋转的加载圆环；1.2 秒后按钮变成绿色并画出对勾；
再过 1 秒恢复原状。收缩约 300ms，使用 ease-in-out。
```

### 03 果冻开关 Jelly Toggle
```
做一个果冻开关（Jelly Toggle）：点击后圆点滑向另一端，滑动途中先横向拉长成胶囊形，
到达终点回弹恢复圆形；底色从灰色渐变为绿色。时长约 350ms，使用带回弹的弹簧曲线。
```

### 04 长按确认 Hold to Confirm
```
做一个长按确认按钮（Hold to Confirm）：圆形删除按钮，按住时外圈进度环顺时针走满，
用时 1.5 秒；中途松手进度环倒退回零；走满后按钮左右轻震一下，变成对勾和"已删除"。
适合删除等危险操作。
```

## 二、视觉规则（原文，放在任何 UI 提示词开头）

```
## 视觉规则
配色：中性色为主，用明暗对比突出主要操作。强调色可选，最多一种。禁用渐变、发光和彩色阴影。
间距：仅用 4 8 12 16 24 32 px。组内间距小于组间间距。
圆角：仅用 6 10 16 px。嵌套圆角：外圆角 = 内圆角 + 内边距。
对齐：同一列元素共用左边缘。
内容：统一一套线性图标。不要表情符号、感叹号或装饰性徽章。
```

## 三、16 种动效的说法（视频原话整理）

| 效果 | 跟 AI 说 |
|---|---|
| 边缘流光 | 「给这张卡片加一个 border beam」——一道光沿边框一圈圈转，用于突出最想让人看到的卡片 |
| 聚光 | 鼠标在卡片上移动时有一团光跟着走，把卡片和边框照亮 |
| 3D 倾斜 | 卡片跟着鼠标位置往不同方向微微倾斜，像拿在手里转着看 |
| 滚动叙事 | 「这一段做成滚动叙事，滚动时左边文字切换，右边图片跟着变」 |
| 乱码解码 | 文字先是一串乱跳的字符，再一个个定格成正确的字 |
| 视差滚动 | 页面往下滚时，背景比前景动得慢，看起来有纵深 |
| 磁吸 | 鼠标靠近按钮，按钮像被吸住一样往鼠标那边挪一点 |
| 打字机 | 文字一个字一个字打出来，后面跟着一闪一闪的光标 |
| 跑马灯 | 一排内容从右往左无限循环地滚；**少数应该匀速走的动效**，鼠标放上去要能停 |
| 流光 | 一道光从表面扫过去；用在加载中的骨架屏上，或按钮上吸引人去点 |
| 数字滚动 | 数字从 0 快速滚到目标值，比如「已服务 1 万位用户」 |
| 滚动出现 | 内容滚进屏幕的时候才淡入或滑入，而不是一打开就全摆在那儿 |
| 弹性 | 动到终点会冲过头一点再弹回来；**别处少用，用多了会显得晃**；弹窗从 0.9 左右放大，别从 0 开始 |
| 错峰 | 「列表项依次出现，**每项间隔 0.05 秒**」 |
| 悬停上浮 | 鼠标放到卡片上，卡片微微浮起来，影子变深，告诉你这块能点 |
| 缓动 | 「你就说动画改成 **ease out** 缓动」；进场减速，离场更快更轻 |

## 四、六种菜单交互的说法（视频原话）

1. **滑动高亮块**：「让选中背景在菜单项之间连续移动，位置和尺寸跟随目标变化，文字保持稳定，快速切换时从当前位置接着走。」
2. **就地展开子菜单**：「子项在父项下方折叠展开，容器高度和后续栏目位置一起变化，子项轻微错峰，当前只保留一组展开。」
3. **顶部下落面板**：「顶部导航展开分组面板，保持面板与触发项的关系，切换内容时不闪白，离开导航区域或按退出键后收起。」
4. **底部悬浮停靠栏**：「做一个底部悬浮导航，按鼠标距离连续调整图标大小，预留放大空间，显示名称和当前项，手机上保留稳定的点击尺寸。」
5. **命令面板**：「加入可点击打开的全局命令面板，支持搜索和键盘选择，处理中文输入法，关闭后恢复焦点，不在输入时自动跳转。」
6. **状态点和计数徽标**：「菜单徽标绑定真实未读状态，数字变化时滚动切换，确认已读后再缩小退出，不改变入口位置。」

## 五、反模式：这些话等于什么都没说

| 你说的 | AI 给你的 | 该怎么说 |
|---|---|---|
| 做个好看的按钮 | 一个会变色的方块 | 见上面四条 |
| 加个加载状态 | 转个圈 | 收缩 300ms → 加载 1.2s → 对勾 |
| 做个开关 | 平平滑过去 | 途中拉长成胶囊形，落位回弹 |
| 删除前确认一下 | 一个弹窗 | 长按 1.5s 走满进度环 |
| 加点高级动画 | 一堆特效堆叠 | 「叫得出名字」+ 参数 |
| 页面好看点 | 渐变 + 发光 + emoji | 视觉规则原文 |
