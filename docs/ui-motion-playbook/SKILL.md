# UI 动效与交互设计手册

## 用途

把"我想要更高级的动效"这类模糊需求，转成**可挑选的效果名 + 可执行的数字参数 + 可验证的闸门**。核心主张：动效不是装饰，是**状态变化的可视化**；说不清在哪变、变多少，就不要加。

## 何时使用

- 用户说"加点动画""更丝滑""更高级""有质感""跟 XX 站一样"
- 要做 hover / 点击 / 展开折叠 / 弹窗 / 抽屉 / 加载 / 数字变化 / 列表进出
- 已有动画显得生硬、突兀、太花，或"一看就是 AI 做的"
- 需要把交互效果写成需求文档或提示词交给 AI 实现

## 工作流

### 第 1 步：动效三问（不清就不加）

对每个候选动画依次回答：

1. **它是否表达了一次状态变化？**（开→关、加载中→完成、A→B）
2. **它是否缩短了等待的感知？**（骨架屏、进度、占位）
3. **它是否提供了空间定位？**（从哪来、到哪去、列表里哪一项）

三条全否 → 不加。答对一条以上 → 继续。这一问能筛掉大部分"AI 味"。

### 第 2 步：按场景选效果

打开 `references/effects-catalog.md`：
- 16 种动效清单（中英名 / 效果 / 适用场景 / 参数 / 反例）
- 6 种遮罩层按**打断程度**排序的选型判据

做后台/管理系统的导航交互时，另读 `references/admin-navigation.md`（"一次点击，六种回应"，含滑动高亮块实现要点）。

### 第 3 步：用数字写参数，不用形容词

读 `references/motion-spec.md`（定量参数与来源）和 `references/ai-prompting.md`（可直接抄的句式）。核心句式：

```
元素 A 在 <触发> 时，用 <时长> + <缓动>，从 <起始态> 走到 <结束态>；
其中属性 B 变化 <具体数值>，同时属性 C 变化 <数值>。
```

禁止"丝滑""高级""自然"，必须给毫秒、像素、透明度、缩放比、颜色值。

### 第 4 步：套令牌，不散落魔法数字

优先复用项目已有令牌；没有就建一套并**全项目统一**（这本身就是"去 AI 味"的第 ② 条）。推荐四档：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--motion-press` | 120ms | 按压、颜色、小图标 |
| `--motion-feedback` | 160ms | hover、展开、滑块位移 |
| `--motion-enter` | 200ms | 入场、页面切换 |
| `--motion-ease` | `cubic-bezier(.22, 1, .36, 1)` | 通用出场曲线 |
| `--motion-spring` | `cubic-bezier(.34, 1.4, .64, 1)` | 仅位移用，带轻微回弹 |

**动手前先全项目搜一遍已有的 `--motion-*` / `--dur-*` / `--ease-*`**，避免造第二套（最常见的自伤）。

### 第 5 步：过闸门

- **无障碍**：所有动画包进 `@media (prefers-reduced-motion: reduce)` 可关闭；装饰性动效（光标跟随、循环背景）不提供。
- **性能**：只动 `transform` / `opacity` / `filter`；必须动布局时用 `grid-template-rows: 0fr → 1fr` 或 `translate`。
- **不抢属性**：入场若用 `transform` + `fill-mode: both`，会锁死终态让 `:hover` 的 `transform` 失效。入场改用独立的 `translate` 属性，`transform` 留给交互。
- **测试环境**：`requestAnimationFrame` / `cancelAnimationFrame` / `document` / `window.matchMedia` 在 Node 单测里通常不存在。动效代码先探存在性，缺失时直接落终值，否则断言会读到动画中间帧。

### 第 6 步：按清单自检

读 `references/review-checklist.md` 逐条过。至少确认：同一屏并存动效 ≤3 种、没有自动循环的装饰动画、数字与文字对齐未被动画破坏。

## 交付方式

交付动效时同时给出四样东西：

1. **效果名**（让用户能自己去搜、去对比）
2. **参数表**（时长/缓动/位移/透明度，可直接粘进代码）
3. **关闭方式**（`prefers-reduced-motion` 下的降级行为）
4. **改动位置**（哪个文件、哪一行）

## 已知反例（不要做）

- 全屏自定义光标层 / 跟随特效（遮数据、无 reduced-motion、纯装饰）
- 首屏自动循环动画（抢注意力、耗电）
- 给表格每一行都加 300ms 入场（信息密度场景反而拖慢阅读；行多时压到 150-200ms 且错峰 16ms）
- 用 `height: auto` 做展开动画（无法过渡，改 `grid-template-rows` 或 JS 测量）
