## 站内通知（D20）

Web主导航和小程序“我的信息”均可进入通知中心。任务进入待确认或失败时，同一事务生成站内通知；重复状态事件不会新增同类消息或清掉已读状态。支持全量/未读筛选、分页、标记已读或未读；点击查看任务先保存已读，再跳转详情。没有回填部署前的历史终态任务，需运行新任务验证通知。

微信订阅消息尚未开通，当前每条消息channelStatus为NOT_REQUESTED，站内功能正常。没有真实微信消息发送，也没有测试其送达率或发送失败恢复；账号绑定、订阅授权和模板条件具备后再接提交后的异步渠道。见[渠道说明](docs/微信订阅消息说明.md)。

## 管理员用户管理（D21）

首个管理员只通过显式初始化配置创建，没有默认用户名/密码，也没有公开的提权接口。直接在原 `application.yml` 的 `lms.admin-bootstrap` 填写账号、密码和显示名称，仅首次初始化时启用。已有管理员或用户名已占用时拒绝初始化，不重设密码、不升级普通用户。成功后清除初始化开关及密码，正常启动。详见[初始化说明](docs/管理员初始化与用户管理.md)。

ADMIN登录后导航显示“用户管理”，支持必要账号字段、关键词/状态筛选及分页；启停需填写原因并确认，状态、撤销会话和审计同事务保存。普通账号调用管理API返回403。停用后Web和小程序旧token失效，重新启用也须新登录；不能停用当前账号或最后一位启用管理员。后台只能经用户送审授权和原因审计查看该版本资料，不提供任意查看私人资料或修改角色的能力。

## 受控审核（D22）

本人从Web或小程序资料详情填写原因，明确授权页面所示版本的正文和原文件进入审核。ADMIN在Web“内容审核”查看队列，填写查看理由并留痕后才能读正文和文件、填写处置原因并确认批准或驳回。资料编辑使旧授权失效，旧记录保留但不能访问或批准；没有自动敏感规则扫描。

驳回限制AI处理并取消未完成任务，本人仍可查阅和修改；修正成新版本后重新送审，批准解除限制，不恢复旧任务。每次决定生成站内通知，两端可跳回本人资料。已获准开始的外部请求无法撤回，活动记录标UNKNOWN；真实微信订阅渠道仍未开通。详细步骤见[受控审核说明](docs/受控审核说明.md)，实现证据见[D22记录](tasks/evidence/D22.md)。

## 统计大屏（D23）

ADMIN登录Web后进入“统计大屏”，默认最近7个上海自然日，也可明确设置日期范围（结束日期不含，最多90天）。当前资料和学科显示全量现状，上传、任务、请求及费用使用所选范围。图表和数据表直接来自数据库聚合，没有固定演示增长数字。

模型和OCR独立尝试含重试/UNKNOWN，缓存和本地工具不算请求；历史模型重试归属未知单列。完成率零分母显示暂无可计算任务，费用缺失显示未提供，不猜币种或补零。V17补模型步骤归属、币种及必要范围索引，历史NULL不伪造回填。详见[统计口径](docs/统计口径说明.md)及[D23验证](tasks/evidence/D23.md)。

## Web 本地启动（D02）

先按上文启动后端，再另开一个终端，在项目根目录执行：

```bash
cd web
npm ci
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`，可注册普通账号、登录、查看本人信息并退出。Web开发服务器把`/api`请求转发到本机8080端口。令牌只放在页面内存，刷新后需要重新登录；注册接口不接收`role`或`status`字段。

登录后进入“我的资料”，可创建、编辑、归档、恢复和删除文字笔记，按标题或正文搜索，并按学科、标签、状态和收藏筛选。列表及详情可收藏或取消收藏本人资料；重复点击不会生成多条收藏，归档资料仍可查看，删除后收藏同步移除。编辑时发送版本号；若收到409，页面保留草稿并展示服务器版本。网页编辑草稿保存在当前标签页的会话存储中，刷新并重新登录后可恢复。

资料列表也可上传JPEG、PNG图片，并在详情页预览原图。单张图片默认不超过10 MiB，解码后最多4000万像素；服务端会核对扩展名、实际类型和大小。重复上传会显示已有资料入口，可由用户确认保存副本。文件默认存于运行后端的系统账户下的`~/.learning-material-system/files`，位于项目目录外；可通过`STORAGE_ROOT`指定其他绝对目录，`FILE_MAX_IMAGE_BYTES`调整服务端图片字节上限。文件只能通过携带会话令牌的`GET /api/v1/materials/{id}/file`读取，不能通过裸路径访问。

“上传 PDF”可一次选择最多10个文件，前端同时上传2个；每个文件独立显示成功、失败或重复结果。单个PDF默认不超过30 MiB、100页，服务端解析后保存页数和SHA-256摘要；密码加密或损坏文件会明确报错。重复文件可打开已有资料或确认保存副本。PDF详情通过授权请求读取文件，在浏览器内预览并提供下载。可用`FILE_MAX_PDF_BYTES`调整服务端字节上限，最大配置值为32 MiB。

资料详情可进入“提交整理任务”，选择生成复习卡片、提炼重点或关联笔记，并填写补充说明。PDF需选择不超过20页的有效页段，提交前需确认外部处理同意。每个账号最多同时保留2个排队或执行中的任务；相同请求键及输入返回原任务，不同输入返回409。Web“整理任务”页和小程序任务页可读取状态和脱敏步骤、取消任务，并在重新同意外部处理后基于当前资料版本创建重试任务。删除原资料会取消对应的非终态任务。D10已实现最多2个worker、30秒租约、10秒心跳、300秒执行时限和epoch写入保护。

D11起提供本地确定性模拟处理器：严格校验`prepare_source`、`generate_summary_cards`、`validate_candidate`工具参数，保存固定版本来源片段和候选摘要、标签、卡片，核验引用后将任务原子地转为`WAIT_CONFIRM`。Web与小程序可预览候选及完整来源，明确显示“模拟生成”。文字笔记引用笔记正文；未启用OCR时，图片只引用标题元数据，实际处理页数为0。候选在用户确认前不会写入正式卡片或资料摘要。

D13对PDF调用本地`extract_pdf_text`，只提取用户所选连续页段（最多20页）的文字层。来源保留实际页码，按资料、版本和页码缓存；同版本重叠页段复用来源。没有文字层的页标记需要OCR或可能为空白，混合PDF只对有文字的页生成模拟候选并列出未识别页；全范围无文字时明确失败，不使用标题假装正文。每片段最多2000个UTF-16代码单元，每任务最多30个片段，超过上限提示缩小页段，不静默截断PDF文字。此步骤不调用外部OCR或模型。

默认`lms.task.worker.enabled: false`，任务仍排队；仅开启worker但未选择处理器时会安全失败并返回`PROCESSOR_NOT_CONFIGURED`。本地联调模拟流程时，在启动后端前设置`lms.task.worker.enabled: true`和`lms.task.processor.mode: mock`。保持默认`lms.ocr.enabled: false`时不调用外部模型或OCR。D14显式开启OCR并配置腾讯云后，图片及所选扫描页会发送给腾讯云，可能产生OCR费用；在mock模式中摘要和卡片仍为模拟生成。配置步骤见[OCR接入配置](docs/OCR接入配置.md)。

D12在待确认任务提供“编辑并确认”入口，可修改摘要、标签和卡片文字，选择部分卡片并逐条勾选关联。确认后，卡片、固定版本来源、所选关系与资料摘要和标签整体保存；重复确认返回同一回执。来源版本变化返回409并保留编辑草稿；保存失败整体回滚。Web“知识卡片”和小程序“我的信息 → 知识卡片”可查阅正式卡片及来源，显示对应的模拟生成或模型生成标识及人工确认状态。来源删除或受限时隐藏引用和片段正文并说明原因。

D17在双端卡片页增加人工新建、编辑、关键词搜索、学科/标签筛选及收藏。人工卡片明确标为“人工创建”，无自动来源；编辑AI卡片后显示“已人工修改”，原引用保留为创建时的历史依据。编辑提交版本号，冲突返回409并保留草稿，不能自动覆盖服务器新版本；收藏不改变内容版本。卡片搜索始终限当前账号，详情来源已删除或受限时继续隐藏原文。D18提供布局与层级，D19提供单独的已确认知识关联关系图。

D18在Web卡片列表提供“组织卡片”入口，可按当前范围拖动位置、输入坐标/堆叠顺序或用方向键移动，保存后刷新恢复；“父子层级图”按人工设置的父级绘制。每次最多200张，超过上限需缩小筛选；保存将完整替换default画布，其他范围的旧位置会先明确提示。布局冲突保留本地位置与旧版本，须读取服务器快照并明确放弃后才替换；父级修改单独校验卡片版本及禁止成环。此功能不调用模型。

D19在Web提供“知识关系图”入口，支持学科精确筛选与中心卡片直接邻域（入边、出边），最多200节点、600条边；有截取时提示部分结果及缩小范围。相关关系无方向，前置知识与示例有方向；点击卡片或关联可核对说明及两端历史来源。人工新建关系需明确读取两端当前版本并填写说明，旧版本409保留输入，重新读取核对后才可确认；重复关系不覆盖原说明。删除只移除关系，保留卡片。小程序在卡片详情提供“已确认关联”，支持分页、类型方向、两端卡片和来源查阅；来源已删或受限继续隐藏原文。

## DeepSeek模型生成（D15）

显式选择`lms.task.processor.mode: model`、`lms.model.provider: deepseek`并在后端配置`lms.model.api-key`后，已同意处理的所选文字才会发送给DeepSeek。默认`lms.model.name: deepseek-flash`；配置步骤见[DeepSeek接入配置](docs/DeepSeek接入配置.md)。缺配置明确失败，不回退假生成。模型输出只允许摘要、标签、卡片和原文引用，服务端校验结构、来源归属和精确引用后进入待确认状态；用户确认前不写正式卡片。

每任务最多两次模型请求尝试（跨租约接管累计），包括一次重试或格式修复。请求记录保留模型、提示版本、token数和未知费用NULL；取消、删除、失租或来源变化不接收迟到结果。未经过OCR的图片不能以标题冒充正文；真实模式笔记超限明确失败。JSON和引用校验不能证明整张卡片事实正确，仍须人工核对。当前真实模型与OCR验收都待本机配置凭证。

## 受限智能体（D16）

显式设置`lms.task.processor.mode: agent`可启用DeepSeek规划循环，密钥及配置脚本沿用D15，详见[DeepSeek接入配置](docs/DeepSeek接入配置.md#d16受限智能体模式)。模型提出受限JSON动作，服务端校验白名单、参数、当前来源与预算后执行，将结果反馈下一次规划。文字PDF无文字页可转OCR；无可用正文或达限明确结束，不使用标题假装已识别。

用户允许关联检索后，按关键词召回本人可访问已有卡片的标题、正文或标签，最多10条有限片段并保留版本。它是关键词检索，不是向量数据库；关联建议只能指向本轮召回卡片，并由用户逐条勾选确认保存。生成阶段不写正式卡片或关系，必须经过validate_candidate及人工确认。D19关系图直接读取这些已确认关系。

任务最多8步（含规划）、4次规划请求、8次模型请求，生成部分最多2次，跨租约接管累计；旧model模式仍最多2次。V11用purpose区分PLANNER与GENERATION，未知费用仍为NULL。工具记录显示实际动作和反馈，不记录隐藏思维；不允许任意SQL、命令、外网URL或删除工具。代码与本地证据见[D16记录](tasks/evidence/D16.md)，真实规划、OCR及计费验收仍待本机凭证。

## 微信小程序本地联调（D03）

先启动后端，再打开微信开发者工具，导入项目中的`miniprogram/`目录。项目默认使用`touristappid`作为本地导入占位；如有自己的小程序AppID，在开发者工具中配置。使用Web端已注册的用户名和密码登录，小程序“我的信息”页应显示与Web相同的用户ID。当前只实现账号密码登录，未模拟微信身份，也未实现微信绑定。

`miniprogram/config.js`默认请求`http://127.0.0.1:8080/api/v1`，只适合电脑上的开发者工具模拟器。本地模拟器联调时，如工具拦截该地址，可仅在开发者工具的本地调试设置中关闭请求域名校验。真机预览或发布前，须换成可从手机访问的HTTPS域名，并在小程序后台配置合法request域名；`127.0.0.1`在手机上指手机自身，不能访问电脑后端。小程序令牌保存在微信本地存储，退出后删除；401也会清理已失效令牌。

请求封装可在项目根目录运行`node --test tests/miniprogram-api.test.js`验证。当前这台Mac的开发者工具命令行服务端口未开启，原生页面登录截图尚未取得，见[D03验证记录](tasks/evidence/D03.md)。

登录后的“我的信息”页可进入资料列表、快速记笔记，也可拍照或从相册上传图片；图片详情通过携带令牌的下载请求读取原图。PDF详情可通过授权下载后使用微信原生文档预览。资料列表可按学科、状态和收藏筛选，列表及详情可收藏或取消收藏。资料详情还可提交整理任务，“我的信息”页可进入任务列表。小程序页面测试可运行`node --test tests/*.test.js`。小程序编辑页在输入时将草稿存入本机，冲突后不替换草稿，保存成功才清理。这些自动化测试不代替微信开发者工具的原生编译与点击验证，当前暂缓该步骤，见[D09验证记录](tasks/evidence/D09.md)。

### 在Windows上运行

在Windows电脑确认已有[JDK 21](https://adoptium.net/temurin/releases?version=21)、[Maven 3.9+](https://maven.apache.org/download.cgi)、[MySQL 8.0](https://dev.mysql.com/downloads/mysql/)和[Git](https://git-scm.com/download/win)，缺少时再安装。打开新的PowerShell，确认`java -version`、`mvn -version`、`mysql --version`和`git --version`可执行。若后续运行Web，需[Node.js 24 LTS](https://nodejs.org/en/download)；运行小程序则需[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。项目不依赖Mac专用路径。

将已提交并推送的项目拉取到Windows，在MySQL中创建独立的空开发库；已有同名开发库时可跳过建库。`root`密码与Windows本机安装时设定的一致，不要将凭证提交到仓库：

```powershell
git clone https://github.com/limou5773-oss/learning-material-system.git
cd learning-material-system
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS learning_material_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;"
```

修改`backend/src/main/resources/application.yml`的数据库账号、密码后启动，不需要设置环境变量：

```powershell
mvn -f backend/pom.xml spring-boot:run
```

模拟流程将YAML的`lms.task.processor.mode`设为`mock`、`lms.task.worker.enabled`设为`true`；真实AI填写密钥后选择`model`或`agent`，OCR按需开启。文件目录通过同一YAML顶层`STORAGE_ROOT`修改，留空沿用当前用户目录。修改后重启后端，资料数据库和文件仍需自行备份。

启动Web时另开一个PowerShell窗口，在项目根目录运行`cd web`、`npm ci`、`npm run dev`，然后访问`http://127.0.0.1:5173`。首次启动前导入完整初始化SQL，已有库本次只执行微信绑定表增量SQL；不要重导已有业务表。Windows上的微信开发者工具模拟器可导入同一个`miniprogram/`目录；后端也运行在这台Windows电脑时，默认本机地址可沿用。真机联调仍需HTTPS合法域名。
