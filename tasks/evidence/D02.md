# D02 Web登录与本人信息：验证记录

日期：2026-10-22。环境：macOS 26.7.1 x86_64、JDK 21.0.12.1、Node.js 24.22.1、MySQL 8.0.46。真实凭证和会话令牌未写入此记录。

## 实现范围

- Flyway V2迁移创建`auth_session`，保存32字节随机会话令牌的SHA-256摘要、7天固定过期时间、客户端类型与撤销时间。
- 注册固定创建`USER`且状态为`ENABLED`；账号名规范化为小写，密码用BCrypt散列。额外`role`、`status`等字段被拒绝。
- 登录返回一次性可见的Bearer令牌；Spring Security对受保护接口逐次查询有效会话与用户状态。退出把当前会话标记为撤销。
- 实现`POST /api/v1/auth/registrations`、`POST /api/v1/auth/sessions`、`DELETE /api/v1/auth/sessions/current`、`GET /api/v1/users/me`，响应遵循`data`/`requestId`契约。
- Vue3页面提供注册、登录、本人信息及退出；令牌仅在页面内存中，不写入浏览器持久存储。

## 验证结果

1. 后端`mvn -B -f backend/pom.xml -DskipTests package`构建成功。
2. 在一次性空库`learning_material_auth_test`执行`mvn -B -f backend/pom.xml test`，Flyway从空库执行V1、V2，认证集成测试1项通过、0失败、0错误、0跳过。测试覆盖未登录401、额外管理员角色字段400、超长UTF-8密码422、注册201、重复用户名409、错误密码401、登录201、本人信息200、退出204、旧令牌401，并检查数据库只存BCrypt密码散列和SHA-256令牌摘要。
3. 在本机开发库做独立HTTP冒烟测试，以上核心状态码及明文不入库检查均通过；测试账号随后删除。
4. `cd web && npm ci && npm run build`成功。浏览器中实际完成注册、登录、查看本人信息和退出，页面跳转正确。见[登录页截图](D02-web-login.jpg)与[本人信息截图](D02-web-profile.jpg)。界面测试账号随后删除。
5. 一次性测试库在验证后已删除，开发库中的Flyway V2迁移保留。后续D03将复用同一账号体系接入小程序。
