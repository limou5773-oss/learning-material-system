# JWT 登录令牌改造

目标：将 Web、小程序共用的随机登录令牌改为 HS256 签名的 JWT，接口字段和 Bearer 请求头保持不变。

- 签发与验证使用 JJWT；JWT 包含签发方、用户 ID、唯一 ID、签发时间及过期时间，不放密码或第三方密钥。
- 原 `auth_session.token_hash` 继续保存整个 JWT 的 SHA-256 摘要；校验 JWT 后仍检查有效会话和当前账号角色，保留退出、修改密码、停用和微信解绑的撤销语义。不新增表或升级普通账号权限。
- 密钥、签发方及期限放入原 `application.yml` 的 `lms.jwt`，期限沿用 7 天；本地生成密钥不输出、不提交。测试使用独立的公开测试密钥。
- 切换后旧随机令牌不再有效，Web 与小程序重新登录。没有新增刷新令牌或旧令牌回退分支。
- 只运行 JWT 和账号相关检查及后端编译，更新受影响的配置、接口和数据库说明；不做全面回归。
