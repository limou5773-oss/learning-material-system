**目标：** 交付可重复运行的本机自动验收、跨模块闭环测试、启动部署/演示步骤和真实证据矩阵，不将自动测试通过写成系统最终验收通过。

**架构：** Node 原生脚本串行执行锁定依赖安装、现有 Node 测试、Maven clean verify 和 Web 构建；保留失败与未执行状态，汇总新生成的 Surefire XML。只接受专用 `learning_material_auth_test` 或下划线后缀数据库，子进程关闭真实厂商与管理员初始化，使用忽略目录存放原始报告。新增 Spring Boot 随机端口跨模块测试，使用真实 MySQL 与本地 MOCK 处理器，验证公开 HTTP 接口贯通。

**技术栈：** Node 24 标准库、JUnit/Spring Boot、MySQL 8、现有 Vue 构建。不增加产品端点、依赖或数据库迁移。

- 文档列出 T01—T18 的具体测试/历史证据和仍待验收项，不把本地 HTTP 桩、MOCK 或软件构造统计写为论文实验。
